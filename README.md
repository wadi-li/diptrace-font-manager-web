# Менеджер шрифтов DipTrace

**[Открыть проект](https://wadi-li.github.io/diptrace-font-manager-web/)**

Публичная веб-версия **1.4.1** для массовой замены шрифтов в схемах `.dchxml` и платах `.dipxml`. Файлы обрабатываются локально в браузере.

## Постоянное название проекта

- RU: **Менеджер шрифтов DipTrace**
- UA: **Менеджер шрифтів DipTrace**
- EN: **DipTrace font manager**
- FRA: **Gestionnaire de polices DipTrace**

Названия изменяются только по прямому указанию владельца. Веб-репозиторий является публикацией того же проекта, а не отдельным инструментом.

## Возможности

- Векторный шрифт DipTrace, Tahoma, Arial и ГОСТ.
- Глобальная и индивидуальная замена в схеме или плате.
- Проверка шрифтов и экспорт встроенных TTF.
- Сохранение исправленного XML без перезаписи исходного файла.

## Локальный запуск

Скачайте `index.html` и откройте в современном браузере. Внешние скрипты не используются.

## Публикация

GitHub Pages: ветка `main`, каталог `/ (root)`.
